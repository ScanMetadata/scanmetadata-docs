# Scan Metadata

[ScanMetadata.com](https://scanmetadata.com) is a fast, free, browser-based utility to inspect, view, and remove EXIF, IPTC, and hidden metadata from images, videos, and documents to ensure digital privacy.

### Key Features
- **EXIF Viewer:** Inspect complete file attributes, camera parameters, and device information.
- **Privacy Stripper:** Remove embedded GPS coordinates and location data prior to sharing files.
- **Client-Side Processing:** Secure and privacy-focused file processing.
